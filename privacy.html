Data and privacy

GainDeck analyzes audio on your Mac using its bundled rsgain engine. The app does not upload your audio for analysis. Choosing Write Tags or Remove Tags changes metadata in the selected files.

Update checks

The upcoming direct edition uses Sparkle to check an update feed on GitHub Pages and download releases from GitHub. Automatic checks are off by default and can be enabled in Settings. Sparkle system-profile reporting is disabled. GitHub receives normal web-request information when you visit this site, check for updates, or download a release.

This website and external links

This site includes no analytics scripts, advertising, or forms. GitHub hosts the site. Support payments open PayPal; issue reports open GitHub; email links open your email app. Those services apply their own policies. Please avoid posting private file paths or personal audio in public issue reports.
